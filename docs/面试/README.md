# SaveAny 面试准备资料索引

> 目标：把这个项目从“跑通过”变成“讲得深、经得起追问”。

## 先做三件事

1. **跑起来**：按 `01-学习计划.md` 的 D0 启动前后端，亲手完成一次“解析 → 总结 → 下载”。
2. **读全景**：`00-项目全景分析.md` 第 1、3、4 节，先建立三条链路的骨架。
3. **做实验**：至少完成 `01` 第 6 节的 E1/E2/E4/E5，面试素材必须来自你亲手做过的观察。

## 三条路线

| 你有多少时间 | 怎么用 |
|--------------|--------|
| 10 天（推荐） | 按 `01-学习计划.md` 的 D0–D10 逐日执行，每天 3h，最后模拟面试 |
| 3 天 | 用 `01` 第 8 节冲刺版：跑通 + SSE + 认证/支付 + 话术 |
| 1 天 | D0 跑通 → `02` 的 2 分钟稿 + 6 个亮点 + 3 个缺陷 + 题库 A/C/F/G |

## 文件说明

| 文件 | 内容 | 什么时候看 |
|------|------|------------|
| `00-项目全景分析.md` | 架构、五条链路、技术决策、数据模型、25 个问题（P0×5 / P1×10 / P2×10）、文档漂移、改造路线 | 学习前通读；面试前复习第 9、12 节 |

| `05-优化记录.md` | AsyncOpenAI、chat 配额、配额原子化 + 失败回滚：问题、改动、实测数据、面试话术 | 已完成的优化，面试讲“我改了什么” |

> `03` 是“按面试出场顺序 + 深度标签（🟢必背/🟡追问/⚪弹药）”写的样板。后面的下载链、SSE 链、支付链可以照这个结构继续写，不要按代码顺序写。

## 三条原则

1. **只讲做过的**：话术里的“我做了”要替换成真实实验；没做过就先做，别背。
2. **先结论后展开**：每个回答按“结论 → 方案 → 取舍 → 反思”组织。
3. **诚实是加分项**：这是教学项目，不编用户量和营收；能指出缺陷并给出修法，比堆功能更有说服力。
