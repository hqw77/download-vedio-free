# 前端速成：只为读懂 SaveAny

> 目标不是成为前端工程师，而是能**读懂、能改、能讲清楚**这个项目的前端。
>
> 你不需要先学完 HTML/CSS/JS 全家桶，也不需要学 Vue Router / Pinia / SSR。这个项目的前端只用到很小一部分。

---

## 1. 你只需要搞懂四件事

1. **模板绑定**：哪个变量显示在页面的哪个位置。
2. **状态**：数据存在哪、什么时候变。
3. **组件通信**：父组件怎么传数据、子组件怎么通知父组件。
4. **请求**：怎么调后端、怎么处理 SSE 流。

CSS、Tailwind 类名、SVG 路径、动画，先全部跳过。它们不影响你理解数据流。

---

## 2. 用后端概念建立心智模型

| 后端概念 | 前端对应 | 说明 |
|---|---|---|
| 类 / 函数 | 组件（`.vue`） | 一个组件 = 模板 + 逻辑 + 样式 |
| 函数参数 | `props` | 父传子，只读 |
| 返回值 / 回调 | `emit` | 子通知父，父监听 |
| 实例字段 | `ref()` | 响应式变量，脚本里用 `.value` |
| `@property` | `computed()` | 由其他状态算出来的值 |
| 监听器 | `watch()` | 状态变化时做副作用 |
| `__init__` | `onMounted()` | 组件挂载后执行 |
| `__del__` | `onBeforeUnmount()` | 组件销毁前清理 |
| `requests` | `axios` / `fetch` | 发 HTTP 请求 |
| 流式响应 | `ReadableStream` | 一段一段读 SSE |

记住一句话：

> **父组件持有状态，子组件收 `props`、发 `emit`；`ref` 变了，模板自动更新。**

## 3. 最小语法清单（半天够用）

### JavaScript

- `const` / `let`、箭头函数 `() => {}`
- 解构：`const { data } = res.data`
- 可选链：`err.response?.data?.detail`
- 模板字符串：`` `Bearer ${token}` ``
- 数组方法：`map` / `find` / `filter`
- `async` / `await`
- `import` / `export`
- `JSON.parse` / `JSON.stringify`

### Vue 3

- 单文件组件三段：`<template>` / `<script setup>` / `<style>`
- 模板指令：
  - `v-if` / `v-else`：条件渲染
  - `v-for`：循环
  - `v-model`：双向绑定
  - `:prop="value"`：传 props
  - `@click="fn"`：监听事件
- `ref()`：响应式变量
- `computed()`：派生值
- `watch()`：监听变化
- `defineProps()` / `defineEmits()`
- `onMounted()` / `onBeforeUnmount()`

> 只看 Vue 官方文档的「Essentials」五节：模板语法、响应式基础、计算属性、生命周期、组件基础。不要从头读到尾。

## 5. 本项目读码顺序

| 顺序 | 文件 | 看什么 | 先跳过 |
|---|---|---|---|
| 1 | `frontend/src/main.js` | `createApp(App).mount('#app')` | - |
| 2 | `frontend/src/App.vue` | 6 个 `ref`、登录/解析/下载/支付函数、两个子组件事件 | 样式、动画 |
| 3 | `components/HeroSection.vue` | 表单 `v-model`、`emit('parse')` | 装饰背景 |
| 4 | `components/VideoResult.vue` | `props`、`defineEmits`、`selectedFormat`、缩略图代理 | SVG 图标 |
| 5 | `components/AuthModal.vue` | 表单、`handleSubmit`、`emit('success')` | 动画 |
| 6 | `api/auth.js`、`api/video.js`、`api/summarize.js` | axios 封装、token、SSE 解析 | - |
| 7 | `components/VideoSummary.vue` | 四个 Tab、SSE 六个回调、markmap、字幕下载 | 导出 PNG/SVG 的细节、CSS |

### `App.vue` 先找这 6 个状态

- `currentUser`：当前用户
- `videoData`：解析结果
- `currentUrl`：当前视频链接
- `loading` / `downloading` / `summarizing`：三个 loading
- `summaryKey`：强制重建总结面板
- `paymentToast`：支付回跳提示

再找 6 个函数：`handleParse`、`handleDownload`、`handleOpenVip`、`restoreUser`、`checkPaymentResult`、`handleLogout`。

## 6. 五个动手练习（按顺序）

1. **改文案**：把 `HeroSection` 的 placeholder 改成你自己的话，刷新页面看变化。
2. **改按钮**：把 `VideoResult` 的“立即下载”改成“保存视频”。
3. **加复制按钮**：在 `VideoResult` 加一个“复制链接”按钮：
   ```js
   async function copyLink() {
     await navigator.clipboard.writeText(props.video.thumbnail)
   }
   ```
   先不追求功能正确，目的是练 `props` 和 `@click`。
4. **字幕搜索**：在 `VideoSummary` 加一个 `keyword` ref，用 `computed` 过滤 `subtitleData.segments`，模板里 `v-for` 渲染过滤后的列表。
5. **显示 format_id**：在格式按钮下面加一行 `{{ fmt.format_id }}`，理解 `v-for` 和字段绑定。

每个练习 10–30 分钟，做完一个再下一个。
